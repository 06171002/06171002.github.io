### 5.2 프로젝트 개요 `/b2b/` · `/stt/`
- **머리**: 프로젝트명, 한 줄 요약, 기간 · 역할
- **담당 기능**: 카드 그리드. 제목, 도메인, 핵심 키워드, 근거 배지. 카드 머리는 노션 커버 이미지 대신 **카드 데이터로 그린 HTML 커버**(프로젝트 색 띠 + 도메인 칩 + 앞 키워드 2개)다 — 커버 SVG 는 흰 바탕 전용이라 다크 모드에서 튀고, 커버 없는 카드도 있다. API 수 · 테이블 수는 프로젝트 내부 정보라 싣지 않는다 (6.5)

### 5.3 상세 `/{project}/{slug}/`
- **머리**: 경로(홈 › 프로젝트), 제목, 메타(도메인 · 기준일), 핵심 키워드
- **기준일**: 노션 마지막 수정일을 "2026-08-30 기준"으로 표시. 본문의 "현재", "5주 전" 같은 상대 표현에 기준점이 생긴다
- **본문**: 1024px 이상이면 오른쪽에 목차 고정, 그보다 좁으면 본문 위에 접힌 목차
- **콜아웃 톤**: 시나리오(문제) · 검증 결과 · 한계 를 구분한다. 한계 콜아웃("이 검증이 말하지 않는 것")은 줄이지 않고 눈에 띄게 둔다
- **대안 표**: ✅ 행을 강조
- **긴 코드**: 25줄을 넘으면 접어 두고 펼치기 (InnoDB 덤프 · 타임라인 같은 텍스트 블록이 길다)
- **꼬리**: 같은 프로젝트의 이전/다음
- 노션 원문 링크는 두지 않는다. 일반화하기 전 원문으로 가는 길이 되기 때문이다

### 5.4 인쇄
상세 페이지를 브라우저 인쇄로 PDF 저장할 수 있게 한다. 헤더 · 목차 · 테마 토글은 숨기고, 토글과 접힌 코드는 모두 펼치고, 링크 뒤에 URL 을 표기한다.

```

  │
  │  pnpm sync                ← 로컬에서만 실행. 노션 토큰은 리포 밖 비공개 폴더 (6.6)
  ▼
scripts/sync/
  1. fetch     공식 API(@notionhq/client)로 허용 목록의 페이지 블록 트리 · 속성 · 커버 조회
  2. exclude   [비공개] 로 시작하는 블록을 자식째(일반 제목이면 그 절째) 제거하고 목록 출력
  3. redact    로컬 치환표 적용 (텍스트 · Mermaid 원문)
  4. convert   블록 → mdast → Markdown
  5. diagrams  Mermaid → SVG (라이트/다크 2벌)
  6. assets    커버 내려받기 (서명 URL 이 곧 만료되므로 즉시)
  7. guard     금지어 · 공개 패턴 검사 → 공개 카드는 걸리면 쓰지 않음, 초안은 경고만 (6.7)
  8. write     공개: src/content/features/… · 초안: src/content/drafts/features/… (+ public/content-assets/ 의 SVG · 커버)
  │
  ▼
git diff 로 변경분 검토 → 커밋 → push
  │
  ▼
GitHub Actions: 2차 가드(시크릿 금지어) → astro check → astro build → Pages 배포
```

### 6.1 왜 "로컬 동기화 + 커밋" 인가
- **공개 전 검토 관문**: 노션을 고쳐도 diff 를 보고 커밋해야만 공개된다
- **토큰이 로컬에만 있다**: CI 는 노션에 접근하지 않고 커밋된 Markdown 만 빌드한다
- **파일이 깨지지 않는다**: 커버 · 다이어그램을 리포에 저장하므로 서명 URL 만료와 무관하다
- **배포가 노션 API 상태에 묶이지 않는다**

### 6.2 변환 방식: 문자열 이어붙이기 대신 AST
노션 블록 JSON 을 mdast(Markdown 문법 트리)로 바꾼 뒤, `mdast-util-to-markdown`(+ GFM 확장)으로 직렬화한다.
- 이스케이프와 인접 서식 문제(`**a****b**` 처럼 강조가 깨지는 경우)를 직렬화기가 처리한다. 수십 곳에서 실제로 생기는 문제다
- 콜아웃 안의 열 안의 목록, 토글 안의 표 같은 중첩 블록을 트리 그대로 옮긴다
- 서식이 같은 텍스트 조각이 연달아 오면 합친 뒤 노드로 만든다
- 콜아웃 · 토글 · 열 · 표 래퍼 · 다이어그램은 **원시 HTML 블록**으로 쓴다: `<aside class="callout tone-red" data-icon="🧪">` + 빈 줄 + Markdown 본문 + 빈 줄 + `</aside>`. CommonMark 표준이라 Astro 7 기본 Markdown 처리기(Sätteri)에서 플러그인 없이 동작한다. MDX 를 쓰지 않으므로 자동 생성 본문의 `{` `<` 이스케이프 문제도 없다
- 강조 기호 안쪽 끝이 구두점이면(`**"따옴표"**로`) CommonMark 강조가 깨지므로 그 경우만 `<strong>` 같은 HTML 태그로 쓴다

### 6.3 블록 매핑

| 노션 블록 | 사용처 | 사이트 출력 |
|---|---|---|
| 제목 H1~H4 | 전체 | 페이지마다 가장 높은 단계를 H2 로 맞춰 일괄 이동. 본문이 "1번", "§5" 로 참조하므로 번호는 유지 |
| 콜아웃 (7색) | 12장 · 242개 | `<aside class="callout tone-…" data-icon>` HTML 블록. 색은 톤으로 보존. 첫 줄이 "이 검증이 말하지 않는 것"이면 `limits`, "시나리오"로 시작하면 `scenario`, 아이콘이 🧪 이면 `evidence` 톤 |
| 콜아웃 본문의 `•` · `- ` 줄 | 다수 | 진짜 목록으로 정규화 |
| 표 | 12장 · 114개 | GFM 표를 `<div class="table-wrap">` 로 감싸 표 안에서만 가로 스크롤. 행 머리글 표는 `row-header` 클래스, ✅ 는 `chosen-mark` 로 감싸 `tr:has()` 로 행 강조. 열 너비 · 셀 색은 버림 |
| 코드 | 11장 · 60개 | Shiki 라이트/다크. `plain text` → `text`. 25줄 초과는 `<details class="code-fold">` 로 접고 요약에 "SQL · 33줄" 표시 |
| Mermaid | 9장 · 20개 | 동기화 때 SVG 로 렌더 (6.4) |
| 인용 | 10장 | `>` |
| 목록 | 4장 | 그대로 |
| 토글 · 토글 제목 | 1장 · 9개 | `<details><summary>` HTML 블록 (토글 제목은 `heading-toggle h{n}` 클래스). 인쇄 때는 펼침 (M4) |
| 열 레이아웃 | 1장 · 4개 | `<div class="columns">` > `<div class="column">`. CSS grid, 좁으면 1열 |
| 색 글자 | 2장 · 47개 | `tc-{색}` · `bg-{색}` 클래스. 흰 바탕 대비 4.5:1 이상으로 조정한 팔레트 |
| 페이지 멘션 | 1건 | 내부 링크 (노션 ID → slug) |
| 「카드 제목」 텍스트 참조 | 약 11곳 | 카드 제목과 정확히 일치하면 내부 링크로 자동 연결 (M3) |
| 빈 블록 | 43개 | 제거 |
| 페이지 커버 | 16개 | 내려받아 저장은 하지만 화면에는 쓰지 않는다 (5.2 — HTML 커버) |

변환기가 처리하지 못한 블록 타입이 나오면 동기화를 실패시킨다. 조용히 빠뜨리지 않는다.

### 6.4 다이어그램 (Mermaid 20개)
- 동기화 때 `mermaid-cli` 로 SVG 를 라이트/다크 2벌 만들어 커밋한다. 테마 토글은 CSS 클래스로 둘 중 하나만 보이게 한다
- 브라우저용 mermaid 라이브러리는 쓰지 않는다. 수백 KB 짜리이고, 렌더 전후로 레이아웃이 흔들려 성능 기준(95)을 지키기 어렵다
- 빌드 때 렌더하는 방식(rehype-mermaid)도 쓰지 않는다. CI 에 헤드리스 브라우저를 설치해야 한다
- alt 는 바로 위 제목을 써서 "{제목} 다이어그램"
- 렌더는 이 PC 의 Chrome · Edge 를 puppeteer 로 띄워서 한다. Chrome 을 따로 내려받지 않는다 (pnpm 이 puppeteer 설치 스크립트를 막아 둠). 다른 PC 면 `PUPPETEER_EXECUTABLE_PATH` 로 지정
- HTML 라벨(foreignObject)은 `<img>` 로 띄울 때 브라우저마다 다르게 보이므로 순수 SVG 텍스트(`htmlLabels: false`)로 그린다
- M1 확인: ERD · 상태 다이어그램 · 플로차트가 라이트/다크 모두 렌더된다
- M2 수정: ER 다이어그램 이름도 `flowchart.wrappingWidth`(기본 200px)로 잘려 긴 엔티티 이름이 글자 중간에서 끊겼다 → 400 으로 올림 (플로차트 폭 변화는 0.4%)
- 원문은 `src/content/…/{slug}/diagram-N.mmd` 로 함께 저장한다 — 커밋되어 diff 로 그림 변경을 읽을 수 있고, `public` 이 아니라 배포에는 나가지 않는다

### 6.5 공개 범위: 프로젝트 내부 정보는 싣지 않는다 (2026-10-19 개정)
회사 이름은 프로필에 이미 나오므로 완전한 익명은 목표가 아니다. 대신 **읽는 사람이 실제 시스템의 내부를 알아낼 수 있는 것은 사이트에 두지 않는다.** 남기는 것은 내가 한 일 — 문제, 검토한 대안과 판단 이유, 결과 수치, 검증 방법, 한계 — 이고, 이것을 개념 이름으로 쓴다.

| 빼거나 일반화하는 것 | 예 | 공개본에서는 |
|---|---|---|
| 인터페이스 | API 경로 · 메서드 · 목록 · 개수 | 뺀다. 필요하면 "주문 생성 API" 처럼 역할로 쓴다 |
| 데이터 구조 | 테이블 · 컬럼 · 인덱스 · 코드값 이름, 컬럼 목록 표, 테이블 수 | 개념 이름("주문 헤더 · 주문 라인")과 개념도로 |
| 코드 | 클래스 · 메서드 · 함수 · 파일 이름, 설정 키, 회사 코드 원문 | 개념 이름의 의사코드. 10줄 넘는 발췌는 줄인다 |
| 구조 · 인프라 | 모듈 · 서비스 구성, 포트, 인스턴스 사양, 배포 설정 | 뺀다. 실측 조건은 "로컬" · "배포 환경" 수준으로 |
| 외부 연동 · 고객 | 결제 · 배송추적 · 조달 시스템 업체, 고객 도메인 | 역할로 일반화 ("PG사", "배송추적 서비스") |
| 운영 보안 상세 | 인증 · 계정 규칙, 미수정 결함의 재현 절차, 결제 민감 컬럼 | 뺀다 |
| 프로젝트 소개 문서 | 개요 · 아키텍처 · 기술 스택 · 데이터 모델 & API · 트러블슈팅 | 사이트에 올리지 않는다 |

오픈소스 · 프레임워크 · AI 모델 같은 **기술 선택**(Spring, FastAPI, Celery, faster-whisper, Gemini 등)은 스킬이라 남긴다.

**공개본은 노션의 공개용 사본이다.** 노션 원문('담당 기능 상세')은 면접용 상세로 그대로 두고, 카드마다 위 기준으로 일반화한 사본을 비공개 '공개용 카드' 데이터베이스에 둔다. 동기화는 사본만 읽는다(slug ↔ 사본 페이지 ID 는 비공개 매핑 6.6). 원문 링크를 밖에 공유하면 원문 쪽 노출은 그대로라는 점은 별개로 남는다.

| 장치 | 하는 일 |
|---|---|
| 사본 작성 | 위 기준으로 일반화한 제목 · 키워드 · 본문. 초안은 Claude 가 쓰고 사용자가 검토한다 |
| `[비공개]` 표식 | 사본 안에서도 뺄 블록에 쓴다. 토글 · 토글 제목 · 콜아웃은 글을 `[비공개]` 로 시작하면 자식째, 일반 제목에 붙이면 같은 단계 이상의 다음 제목 전까지 절째 뺀다(노션 일반 제목은 자식이 없어 제목만 빼면 본문이 남으므로). 뺀 목록을 동기화 결과에 출력한다. 🔒 같은 아이콘은 표식이 아니다 — 잠금 · 암호화를 다루는 카드가 내용 아이콘으로 이미 쓴다 |
| 치환표 | 사본에 남은 고유 표기를 잡는 안전망 (비공개) |
| 가드 | 공개 패턴(식별자 · 파일 이름 · API 경로 · 인스턴스 사양 등) + 비공개 금지어. 공개 기준 점검(`--check`)이 0건이어야 공개한다 |

**가드 검사 대상**: 생성된 Markdown(프런트매터 포함), Mermaid 원문과 SVG(텍스트가 들어 있다), 커버 SVG.
PNG 커버는 글자를 검사할 수 없으므로 눈으로 확인한다.

### 6.6 비밀 정보를 두는 곳

비공개 자료는 **리포 밖** 형제 폴더 `../portfolio-private/` (로컬 `C:\dev\portfolio-private\`)에 둔다. 리포 안에 없으므로 실수로 커밋될 수 없다. `.gitignore` 에도 같은 이름을 넣어 2차로 막는다. 동기화 스크립트는 이 폴더 경로를 환경변수 `PORTFOLIO_PRIVATE_DIR` 로 받고, 없으면 `../portfolio-private` 를 쓴다.

| 장치 | 위치 | 공개 여부 |
|---|---|---|
| 치환표 (원문 표현 → 공개용 표현) | `portfolio-private/sync.local.json` | **비공개**. 리포에 올리면 숨기려던 이름이 그대로 공개된다 |
| 노션 페이지 ID · URL ↔ slug 매핑 (공개용 사본) | `portfolio-private/sync.local.json` | **비공개**. 노션이 링크 공개 상태라면 노션 페이지로 가는 길이 된다 |
| 노션 토큰 | `portfolio-private/.env` | **비공개** |
| 공개 전 점검 목록 | `portfolio-private/public-review.md` | **비공개** |
| 공개 패턴 (내부 테이블 접두사, IP, `호스트:포트`, API 경로 — 표 칸에 경로만 있는 것 포함, 파일 이름, 대문자 식별자, 클래스 · 필드 · 함수 이름, 인스턴스 사양) | `guard.config.ts` | 공개해도 되는 규칙. 표준 라이브러리 · 오픈소스 이름만 허용 목록에 둔다 |
| 고객 도메인 · 연동 업체 이름 | `portfolio-private/sync.local.json` 금지어 | **비공개**. 공개 규칙에 적으면 그 자체가 노출이다 |
| CI 금지어 목록 | Actions 시크릿 `PUBLIC_DENYLIST` | 비공개 |

- 1차 가드(동기화)는 치환 **뒤의** 결과를 금지어 · 치환표의 원문 키 · 공개 패턴으로 검사한다. 공개 카드는 하나라도 걸리면 파일을 쓰지 않으므로, 유출이 공개 리포의 git 이력에 남기 전에 막힌다 (6.7)
- 2차 가드(CI)는 빌드 결과(`dist/`) 전체를 시크릿 금지어로 검사한다. Markdown 을 손으로 고친 경우도 잡는다
- 걸리면 치환표에 변형 표기(대소문자, 띄어쓰기 등)를 추가하고 다시 동기화한다
- 가드는 lockfile 해시 같은 무작위 문자열에서 오탐이 나므로 생성 결과(Markdown · SVG · dist)만 검사한다

### 6.7 초안과 공개
공개 리포라서 **커밋하는 순간 공개**된다. 그래서 공개 점검 전 카드는 리포에 들어가면 안 된다.

| `sync.config.ts` 의 `publish` | 쓰는 곳 | 가드 |
|---|---|---|
| `false` (초안) | `src/content/drafts/features/…` · `public/content-assets/drafts/…` — gitignore 라 CI 빌드에는 존재하지 않는다. 로컬 미리보기 전용, 페이지 위에 "초안" 띠 | 경고만 하고 쓴다 |
| `true` (공개) | `src/content/features/…` · `public/content-assets/…` — 커밋 대상 | 하나라도 걸리면 쓰지 않는다 |

- `pnpm sync --check [slug …]` — 공개 기준으로 가드를 미리 돌린다 (파일은 쓰지 않음). `publish: true` 로 바꾸기 전에 쓴다
- 가드 통과 ≠ 공개 점검 완료. 가드는 문자열 패턴만 보므로 회사 코드 발췌 · 결함 서술 같은 내용 항목은 공개 점검 목록으로 따로 확인한다

## 7. 콘텐츠 모델

노션 '공개용 카드' DB 속성(이름 · 도메인 · 핵심 키워드)과 대응시키고 Zod 로 검증한다. 동기화 결과가 스키마와 어긋나면 빌드가 실패한다.

```ts
// src/content.config.ts (요지, Astro 7 기준)
import { defineCollection } from 'astro:content';
import { glob } from 'astro/loaders';
import { z } from 'astro/zod';

// 프론트매터의 slug 가 엔트리 id 가 된다 (glob 로더 규칙) → 라우트 /{project}/{id}/

// features/ = 공개 점검을 마친 카드(커밋) · drafts/features/ = 점검 전 초안(gitignore — CI 빌드에는 없음)
const features = defineCollection({
  loader: glob({ pattern: '{features,drafts/features}/**/index.md', base: './src/content' }),
  schema: z.object({
    title: z.string(),                          // 기능명
    project: z.enum(['b2b', 'stt']),
    order: z.number().int(),
    domain: z.string().nullable(),              // 도메인 (select)
    keywords: z.array(z.string()),              // 핵심 키워드 — '·' 와 ',' 로 분리 (API 수 · 테이블 수는 싣지 않는다 6.5)
    evidence: z.array(z.enum(['measured', 'tested', 'static', 'estimated'])),
    draft: z.boolean(),                         // publish: false 로 동기화된 초안 (6.7)
    cover: z.string().nullable(),               // 커버 경로 (public/content-assets/…)
    notionEditedAt: z.coerce.date(),            // 기준일
  }),
});
```

- `notionId` 는 프론트매터에 넣지 않는다 (6.6)
- 노션 '프로젝트 소개' 문서는 사이트에 올리지 않으므로 docs 컬렉션은 만들지 않는다 (6.5, 2026-10-19 개정)
- 프로필 · 스킬 · 대표 수치는 노션 동기화 대상이 아니다. 노션 메인 페이지의 열 · 콜아웃 배치에 기대어 파싱하면 깨지기 쉽고 바뀔 일도 드물다. `src/data/*.ts` 에서 직접 관리하며, 바꿀 때는 노션과 두 곳을 고친다

## 12. 버린 대안

| 대안 | 버린 이유 |
|---|---|
| 빌드할 때마다 노션 API 로 직접 렌더 (노션 로더) | 노션 수정이 검토 없이 바로 공개된다 · 토큰을 CI 에 둬야 한다 · 노션 장애가 배포를 막는다 |
| 노션 '웹에 게시' 링크만 사용 | 디자인 · 주소 · 검색 노출을 통제할 수 없고 일반화도 불가 |
| 문자열 이어붙이기 변환기 | 이스케이프 · 인접 강조 · 중첩 블록에서 깨진다 → AST 변환 |
| MDX 생성 | 자동 생성 본문의 `{` `<` 이스케이프 문제 → Markdown + 원시 HTML 블록 |
| remark-directive 지시문(`:::callout`) | Astro 7 기본 처리기(Sätteri)는 remark 플러그인을 돌리지 않아 unified 처리기를 따로 설치해야 한다. `상태:DONE` 의 `:DONE` 처럼 본문 글자가 지시문으로 잘못 읽히는 함정도 있다 → 원시 HTML 블록 |
| 🔒 아이콘을 비공개 표식으로 | 잠금 · 암호화를 다루는 카드가 이미 내용 아이콘으로 쓴다 → `[비공개]` 글머리 |
| 브라우저에서 Mermaid 렌더 | 수백 KB JS, 레이아웃 흔들림 → 동기화 때 SVG |
| 빌드 때 Mermaid 렌더 | CI 에 헤드리스 브라우저 필요 → 동기화 때 SVG |
| Next.js 정적 내보내기 | 이 규모에 비해 클라이언트 JS 와 설정이 과하다 |
| 프로필 · 스킬까지 노션에서 파싱 | 노션 배치에 의존해 깨지기 쉽다. 바뀔 일이 드문 데이터다 |
| 치환표를 리포에 커밋 | 숨기려던 이름이 공개 리포에 그대로 남는다 |
